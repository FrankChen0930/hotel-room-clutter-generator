1. 架構判斷

整體看法： 現有兩套生成器都屬於「人工寫好的情境模板，加上局部隨機擾動」，還不算參數化的生成器。真正的參數化生成器（由 Scenario × Level 推導出要放哪些物件），才是 V1.0 最主要的新工作。幾何檢查、疊加層輸出、Manifest、Replay 都已經有可用的實作，大部分可以直接沿用。

4. 架構風險

等級: CRITICAL
風險: Seed 的語意錯誤（已查證，generate.py:127-140）：i=seed-706 只是查表索引，物件數量隨 i 增加。Seed
  709 會 IndexError，Seed 705 會靜默拿到 patterns[-1]
後果: 36 案例的「3 Seeds × 3 Levels」無法成立；Seed 和亂度程度互相混淆
處理: 新的 Planner 一定要讓 Seed 只控制隨機性、Level 只控制數量和分布。舊 recipe 只保留作為 legacy
  fixture
────────────────────────────────────────
等級: IMPORTANT
風險: PhysX worker 只支援「單一 Cube collider」（已查證，physics.py:153、:180）
後果: 實際只測過 BOOK 和 TISSUE。原生的 Mug、Water、Tea、Cookie、紙張、罐子都沒有動態證據
處理: 在 Catalog 加 physics_proxy（box / convex / none）。worker 改成支援多 shape。沒有代理的物件標成
  STATIC_ONLY，不算 FAIL
────────────────────────────────────────
等級: IMPORTANT
風險: S0 跨房型（已查證）：YAZHI 的 S0 綁定床。Pillow 放在床墊上；HalfOpenTowel 是投影到 duvet
  三角面的貼合形態。Hotel 705 有自己的原生 Pillow、Duvet、Towel_Stack
後果: 要在 Hotel 換上 YAZHI 的枕頭，就得停用原生 prim，這會跟 validate() 的 source override whitelist
  衝突
處理: V1 的 S0 改選毛巾放在平面支撐上（詳見第 8 節）
────────────────────────────────────────
等級: IMPORTANT
風險: 資產授權：asset_states.json 標記 INTERNAL_EVALUATION_ONLY 和 REDISTRIBUTION_NOT_CLEARED
後果: 會直接影響「可交付研究者使用」這項需求
處理: 交給 Human 決定交付範圍；Catalog 記錄授權欄位
────────────────────────────────────────
等級: IMPORTANT
風險: 靜態檢查用旋轉後的世界 AABB，並且要求所有角點都在支撐面上
後果: 高亂度時可行率會掉，觸發 fallback 或失敗
處理: M3 前做一次 high level 可行率 spike；不足再換 OBB 或格點
────────────────────────────────────────
等級: IMPORTANT
風險: 每個案例都要啟動 Isaac 一次，會影響時間預算
後果: 36 案例乘上各層驗證，耗時不可知
處理: 以一個場景一次 sim 為原則；rays 和 settle 合併在同一個 session
────────────────────────────────────────
等級: OPTIONAL
風險: 驗證依賴 assert，用 python -O 跑會被跳過
後果: 驗證會被靜默略過
處理: 改成明確的 raise。可以隨重構順手修

6. 更簡單的替代方案

1. 以修正階梯取代 Physics Feedback 模組。 順序是：
   a. 同一支撐面重新取樣
   b. 換到允許的支撐面（現有 800／1600 fallback 已實作）
   c. 降級為 lying 姿態
   d. 移除物件並記錄

   每一階都寫入 lineage，物理失敗後只重跑一次。不需要建 solver。
2. 用一個 Manifest v3，取代多份 state 檔。 內容包括來源狀態（原生物件的初始矩陣，prepare.py:96 已有）、最終狀態、所有嘗試紀錄、驗證結果指標。舊格式只寫匯入器，不回頭改歷史檔。
3. 每個物件一條獨立 RNG 串流。 用 hash(seed, request_id) 產生，就不會出現「加一個物件導致全部漂移」的問題。只需幾行程式，不需要框架。
4. S0 用離線烘焙的固定 mesh。 用 Blender 或 Isaac cloth 對一種毛巾在平面上掉落並烘焙一次，凍結成 USD state。這會成為 S1 的自然起點，而且不阻塞 V1。
