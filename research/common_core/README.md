# Common Core V1.0

Data-driven clutter generation for Hotel705 and YAZHI-TWIN. The frozen policy
defines two scenarios, three levels and separate selected towel states.
Scenes are new relative overlays; existing sources and assets stay read-only.

Start with [Quick Start](docs/QUICK_START.md), [CLI](docs/CLI.md),
[S0 scope](docs/S0.md) and [progress evidence](docs/PROGRESS.md).

The release candidate requires the complete Roadmap acceptance evidence and a
separate independent researcher handoff. A generated scene's STATIC_PASS is
limited to its recorded layers. Unselected objects have no dynamic qualification.

Local source bindings are required. The code-only delivery contains no source USD,
textures, legacy repositories, historical evidence or redistributed SDK binaries.
