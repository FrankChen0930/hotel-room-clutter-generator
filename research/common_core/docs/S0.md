# Static towel states

`s0_towel` reuses the adopted `FoldedTowel` and refined `LooseTowel` USD assets.
Each state has its own locator, SHA, geometry identity, pivot, bounds and
support envelope. Both remain `STATIC_ONLY`; no cloth simulation or inherited
dynamic qualification is claimed. Sources and historical adoption records are
read-only and are listed in `config/source_lock.json`.

The current Scenario/Level Policy omits towels at `low`, requests one folded
towel at `medium`, and one loose towel at `high`, in both scenarios. State
selection is data-driven; seeds do not index recipes. Count ranges retain the
Functional Spec's initial values. Release coverage policy is not frozen until
WU-10 acceptance.

The eight dedicated acceptance fixtures cover both states, both rooms and both
scenarios. Hotel uses the bench and desk; YAZHI uses the round table and cabinet.
The YAZHI bench was rejected for the loose state: after two 12 mm edge margins,
its usable width is 281 mm, below the state's 283.78 mm conservative width.
No clearance or seed was relaxed. The failed attempt is retained.

These are explicitly one-object support/state fixtures, separate from the
formal 36 Level/count cases. Each fixture saves its own profile, catalog,
policy, source lock and deployment file, so its input identity can be replayed
without changing the main policy.

Generate a fresh dedicated fixture set from the code directory:

```powershell
& C:/isaac_sim/kit/python/python.exe -B tools/generate_s0_eight.py --output 'C:/hotel_room/_common_core_runs/my new S0 fixtures'
```

Replay one fixture with its saved deployment and manifest into a new output:

```powershell
& C:/isaac_sim/kit/python/python.exe -B run_core.py replay --config '<fixture>/deployment.json' --manifest '<fixture>/attempts/a000/manifest.json' --output 'C:/hotel_room/_common_core_runs/my new S0 replay'
```

Static/Replay/Integrity results do not imply Native Support or Visual PASS.
Native support reports, actual images and agent visual reviews are separate
assessments bound to the same manifest SHA and state digest. A cropped image
remains in evidence; supplemental views are written into a new assessment.
Agent review is separate from human handoff acceptance.
